# **Healthcare Dataset Analysis**

## **Project Overview**

This project analyzes a healthcare dataset using **Python, Pandas, Matplotlib, and Seaborn**.

The analysis focuses on:

* Patient information
* Medical conditions
* Admission details
* Billing amounts
* Hospital stay duration
* Monthly admission trends

## **Dataset**

The dataset contains healthcare-related patient information such as:

* Patient ID
* Gender
* Age
* Medical Condition
* Admission Date
* Admission Type
* Medical Code
* Billing Amount
* Discharge Date

## **Technologies Used**

* Python
* Pandas
* Matplotlib
* Seaborn
* Google Colab

## **Data Analysis**

The following operations were performed:

* Loaded the healthcare dataset using Pandas.
* Checked the dataset columns.
* Checked for missing values.
* Converted admission and discharge dates into date format.
* Calculated the number of days of hospital stay.
* Calculated total billing amount for each medical condition.
* Analyzed billing amounts using visualizations.
* Analyzed patient admissions by month.
* Calculated the correlation between age, hospital stay, and billing amount.

## **Visualizations**

The project includes:

* Bar chart for billing amount by medical condition.
* Violin plot for billing amount by medical condition.
* Violin plot for billing amount by admission type.
* Line plot for monthly patient admissions.
* Heatmap showing correlations between age, hospital stay, and billing amount.

## **Objective**

The main objective of this project is to analyze healthcare data and identify useful patterns related to:

* Patient admissions
* Medical conditions
* Hospital stay duration
* Billing amounts
* Admission types
* Monthly admission trends
* Relationships between age, hospital stay, and billing

* Download or clone the repository.
* Open `Week_6.ipynb` in Google Colab or Jupyter Notebook.
* Make sure `healthcare_dataset.csv` is available.
* Update the dataset path if required.
* Run the code cells to perform the analysis.

## **Conclusion**

This project demonstrates how **Python** can be used to analyze healthcare data and create meaningful visualizations. **Pandas** is used for data processing and analysis, while **Matplotlib** and **Seaborn** are used to visualize billing patterns, admission trends, and correlations.
